📦 Установка и запуск проектов
Требования к системе:
Операционная система: Windows 10/11, macOS, или Linux

Память: минимум 4 GB RAM

Место на диске: 2 GB свободного места

Инструкция по скачиванию и запуску:

📥 1. Скачайте проект:
bash
# Вариант A: Клонируйте репозиторий
git clone https://github.com/ваш-ник/quantum-password-generator.git
cd quantum-password-generator

# Вариант B: Скачайте ZIP
# 1. Нажмите "Code" → "Download ZIP"
# 2. Распакуйте архив
⚙️ 2. Установите зависимости:
bash
# .NET SDK 6.0:
# https://dotnet.microsoft.com/download/dotnet/6.0

# Python 3.8+:
# https://python.org/downloads

# Библиотеки:
pip install qsharp
🚀 3. Запустите проект:
bash
# Перейдите в папку проекта
cd quantum-password-generator

# Запустите генератор паролей
python pass.py

# Следуйте инструкциям в терминале
📁 Структура проекта после скачивания:
text
quantum-password-generator/
├── pass.py                 # Запускайте эту команду
├── qsharp.json            # Конфигурация Q#
└── src/
    └── PasswordGenerate.qs # Q# код
Просто скачайте → установите Python и .NET → запустите python pass.py
